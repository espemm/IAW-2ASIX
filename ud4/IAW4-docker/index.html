    Docker¶

    Docker és una plataforma de programari de codi obert dissenyada per facilitar la creació, la implementació i l’execució d’aplicacions mitjançant l’ús de contenidors.

    Contenidors vs. Màquines Virtuals¶

    A diferència de les màquines virtuals (VM), que són pesades perquè inclouen un sistema operatiu complet i requereixen un hipervisor per gestionar el maquinari, els contenidors són lleugers.

    Els contenidors comparteixen el nucli (kernel) del sistema operatiu host, cosa que evita la duplicitat de recursos i permet que arrenquen quasi instantàniament.

    Analogia: Imagineu que una màquina virtual és una casa independent amb els seus propis fonaments i canonades; un contenidor és un apartament en un edifici que comparteix l’estructura central (el nucli) però manté el seu propi espai privat.

    Conceptes Fonamentals¶

    Per treballar amb Docker, cal entendre quatre pilars:

    1. Imatge: És una plantilla immutable que conté les instruccions per crear un contenidor. Es pot veure com la “recepta” o classe en programació.
    2. Contenidor: És la instància en execució d’una imatge. És l’entorn aïllat on s’executa l’aplicació.
    3. Dockerfile: Un fitxer de text pla amb les instruccions necessàries (ordres com FROM, COPY, RUN) per construir una imatge personalitzada.
    4. Docker Hub / Registry: Un servei (com GitHub, però per a imatges) on s’emmagatzemen i descarreguen imatges oficials i de la comunitat.

    Instal·lació¶

    Docker CE està disponible per als sistemes GNU/Linux següents: CentOS, Debian, Fedora i Ubuntu. No totes estan en múltiples arquitectures, però sí que totes suporten x86_64/amd64.

    La seua instal·lació dependrà del sistema operatiu i la distribució. Per tant, caldrà seguir la documentació oficial:

    • Ubuntu: https://docs.docker.com/install/linux/docker-ce/ubuntu/
    • Debian: https://docs.docker.com/install/linux/docker-ce/debian/
    • CentOS: https://docs.docker.com/install/linux/docker-ce/centos/
    • Fedora: https://docs.docker.com/install/linux/docker-ce/fedora/

    Inici

    La recomanació per comprovar si la instal·lació és correcta, consisteix en executar el contenidor hello-world

    docker run hello-world

    El resultat serà, si ja està descarregada la imatge:

    Hello from Docker!

    to your terminal.

To try something more ambitious, you can run an Ubuntu container with:
 $ docker run -it ubuntu bash

    Si la imatge no està descarregada, se descarregarà i crearà el contenidor abans d’executar-lo.

    Execució¶

    L’execució d’un contenidor hem vist que s’executa de manera senzilla:

    $ docker run nom_del_contenidor

    L’execució també pot ser interactiva. En aquest cas es fa servir l’opció -i per obrir una sessió interactiva, -t permet crear un pseudo-terminal per a interaccionar amb el contenidor, el nom del contenidor s’indica amb l’opció –name, s’indica la imatge per a crear-lo (ubuntu en l’exemple), i per últim la comanda que executarem (bash en l’exemple)

    $ docker run -it --name contenidor1 ubuntu bash
root@2bfa404bace0:/#

    El contenidor es para quan eixim. Per tornar a iniciar-lo:

    $ docker start contenidor1
contenidor1
$ docker attach contenidor1
root@2bfa404bace0:/#

    Si el contenidor està en marxa podem executar ordres amb el subordre exec:

    $ docker start contenidor1
contenidor1
$ docker exec contenidor1 ls -al

    Amb l’ordre docker restart reiniciem el contenidor.

    Per mostrar informació d’un contenidor, executem docker inspect:

    $ docker inspect contenidor1
[ 
{ 
"Id": "178871769ac2fcbc1c73ce378066af01436b52a15894685b7321088468a25db7", 
"Created": "2021-01-28T19:12:21.764255155Z", 
"Path": "bash", 
"Args": [], 
"State": { 
"Status": "exited", 
"Running": false, 
"Paused": false, 
...

    Ens mostra molta informació, està en format JSON (JavaScript Object Notation) i ens dóna dades sobre aspectes com ara:

    • L’ID del contenidor.
    • Els ports oberts i les seues redireccions
    • Els bind mounts i volums usats.
    • La mida del contenidor
    • La configuració de xarxa del contenidor.
    • L’ENTRYPOINT és el que s’executa en fer docker run.
    • El valor de les variables dentorn.
    • …

    En realitat, totes les imatges tenen definides un procés que s’executa; en concret, la imatge ubuntu té definida per defecte el procés bash, per la qual cosa podríem haver executat:

    $ docker run -it --name contenidor1 ubuntu

    L’execució d’un contenedor en segon pla s’aconsegueix amb l’opció -d

    $ docker run -d --name contenedor2 ubuntu

    LA parada del contenidor i esborrat:

    $ docker stop contenidor2
$ docker rm contenidor2

    Cal tenir en compte que un contenidor que s’està executant no pot ser eliminat. Tindríem que parar el contenidor i posteriorment esborrar-lo. Una altra opció és esborrat a la força:

    $ docker rm -f contenidor2

    Contenidor web¶

    Exemple de creació d’un servidor web amb Apache a partir de la imatge del registre públic docker hub:

    $ docker run -d --name servei-apache -p 8080:80 httpd

    Veiem que el contenidor s’està executant, a més amb l’opció -p mapegem un port de l’equip on tenim instal·lat el docker, amb un port del contenidor: Si accedim a la ip de l’ordinador que té instal·lat docker al primer port indicat, es redigirà la petició a la ip del contenidor al segon port indicat. Mai utilitzem directament la ip del contenidor per accedir-hi.

    Accedir des d’un navegador a la IP del servidor amb docker al port 8080:

    Accedir al log del contenidor executant:

    $ docker logs servei-apache

    Amb l’opció logs -f seguim visualitzant els logs en temps real.

    Modificació del contingut sel servidor web

    Si consultem la documentació de la imatge httpd al registre docker Hub, podem determinar que el servidor web que s’executa al contenidor desar els seus fitxers (directori DocumentRoot) a /usr/local/apache2/htdocs/. Crearem un nou fitxer index.html en aquest directori.

    Ho podem fer de diverses maneres:

    Accedint de forma interactiva al contenidor i fent la modificació:

    $ docker exec -it servei-apache bash

root@cf3cd01a4993:/usr/local/apache2# cd /usr/local/apache2/htdocs/
root@cf3cd01a4993:/usr/local/apache2/htdocs# echo "<h1>2ASIX - Docker - IAW</h1>" > index.html
root@cf3cd01a4993:/usr/local/apache2/htdocs# exit

    Executant directament l’ordre de creació del fitxer index.html al contenidor:

    $ docker exec servei-apache bash -c 'echo "<h1>2ASIX - Docker - IAW</h1>" > /usr/local/apache2/htdocs/index.html'

    Variables d’entorn¶

    Per a crear un contenidor que necessita alguna configuració específica, el que farem és crear variables d’entorn al contenidor, perquè el procés que inicialitza el contenidor puga aplicar esta configuració.

    Per a crear una variable d’entorn, en crear un contenidor, utilitzarem -e o --env:

    $ docker run -it --name prova -e USUARIO=prova ubuntu bash
root@91e81200c633:/# echo $USUARIO
prova
