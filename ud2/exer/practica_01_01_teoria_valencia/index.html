    1. Introducció i objectiu¶

    En aquesta pràctica es treballa amb una pila LAMP (Linux, Apache, MySQL, PHP) en una instància de servidor.\ S’aprèn a configurar Apache perquè servesca continguts HTML/PHP, gestionar directoris i crear host virtuals, entre altres coses.

    2. Configuració de directoris a Apache¶

    Bloc d’exemple:

    <Directory /home/ubuntu/misitioweb>
    Options Indexes FollowSymLinks
    AllowOverride None
    Require all granted
</Directory>
    • Options Indexes FollowSymLinks: permet llistar continguts i seguir enllaços.\
    • AllowOverride None: impedeix l’ús de .htaccess.\
    • Require all granted: dóna accés a tots els clients.\ Després cal reiniciar Apache:
    sudo systemctl restart apache2

    3. Habilitar / deshabilitar mòduls d’Apache¶

    Activar un mòdul:

    sudo a2enmod nom_del_modul
sudo systemctl restart apache2

    Exemple:

    sudo a2enmod rewrite

    Desactivar:

    sudo a2dismod nom_del_modul
sudo systemctl restart apache2

    4. Directiva DirectoryIndex¶

    Defineix l’ordre de fitxers que Apache servirà per defecte:

    DirectoryIndex index.php index.html

    Apareix en la configuració global o en cada virtual host.

    5. Host virtuals (Virtual Hosts)¶

    Permeten que un mateix servidor gestione diversos dominis.

    1. Crear un fitxer, per exemple /etc/apache2/sites-available/miweb.conf.\

    2. Definir ServerName, DocumentRoot, logs, etc.\

    3. Activar:

      sudo a2ensite miweb.conf
sudo systemctl reload apache2

    4. Desactivar el host per defecte si cal:

      sudo a2dissite 000-default.conf
sudo systemctl reload apache2

    També es pot editar /etc/hosts per fer proves locals.

    6. Protecció de directoris amb .htaccess¶

    Exemple d’autenticació bàsica:

    AuthType Basic
AuthName "Accés restringit"
AuthUserFile "/etc/apache2/.htpasswd"
Require valid-user

    Cal permetre AllowOverride All en la configuració del directori:

    <Directory "/var/www/html/stats">
    AllowOverride All
</Directory>

    Crear .htpasswd amb:

    sudo htpasswd -c /etc/apache2/.htpasswd usuari

    7. Resum i consideracions finals¶

    • Configura correctament directoris i permisos.\
    • Activa només els mòduls necessaris (rewrite, etc.).\
    • Usa DirectoryIndex per definir fitxers predeterminats.\
    • Amb virtual hosts pots allotjar diverses webs.\
    • .htaccess permet personalitzar configuracions locals amb precaució.
