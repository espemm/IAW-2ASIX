    Pràctica 6: Login i registre d’usuaris¶

    Objectiu¶

    • Desenvolupar un sistema funcional de login i registre d’usuaris amb PHP i MySQL.
    • Aplicar conceptes de seguretat, validació de dades i maneig de sessions per garantir la funcionalitat i la protecció del sistema.

    Requisits Tècnics¶

    • Servidor web que suportie PHP amb nginx.
    • PHP 7.0 o superior.
    • MySQL/MariaDB com a sistema de gestió de bases de dades.

    Funcionalitats a implementar¶

    • Formulari de Registre

    • Validar que els camps d’entrada no estiguen buits.

    • Assegurar-se que la contrasenya i la confirmació coincideixin abans de guardar-les.

    • Guardar el nom d’usuari i la contrasenya (en format hash) a la base de dades.

    • Formulari de Login

    • Validar les dades introduides, que siguen correctes.

    • Verificar que l’usuari i la contrasenya coincideixin amb les dades guardades en la base de dades.
    • Si el login és correcte, s’iniciarà una sessió amb el nom de l’usuari.

    • Mostrar un missatge, si el login falla, degut a usuari o password incorrectes.

    • Gestió de Sessions

    • Utilitzar $_SESSION per mantenir l’estat de l’usuari una vegada loguejat.

    • Assegurar-se que la sessió es tanque correctament al fer logout.

    • Seguretat

    • Utilitza password_hash per a guardar les contrasenyes de forma segura.

    • Utilitza password_verify per a comparar les contrasenyes al fer login.
    • Valida totes les dades d’entrada per evitar injeccions SQL o atacs XSS.

    Tasques a fer¶

    Crear Base de datos¶

    En mysql, des de phpmyadmin, crear la base de dades destinada a guardar els usuaris i contrassenyes de la pàgina/aplicació web.

    Una opció és executar el codi SQL en l’entorn web:

      CREATE DATABASE logins CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
  USE logins;

  CREATE TABLE users (
      id INT AUTO_INCREMENT PRIMARY KEY,
      usuari VARCHAR(50) NOT NULL UNIQUE,
      password VARCHAR(255) NOT NULL,
      created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  );

    Crear un usuari per a gestionar les operacions amb aquesta base de dades, i que siga diferent al usuari root o administrador del gestor de bases de dades:

      CREATE USER 'elTeuUsuari'@'localhost' IDENTIFIED WITH caching_sha2_password BY 'ElTeuPassword';
  GRANT ALL PRIVILEGES ON logins.* TO 'louser'@'localhost';
  FLUSH PRIVILEGES;

    Pàgines¶

    Connexió a la Base de dades

      //----------bd.php----------//
  <?php
  $host = 'localhost';  // Equip servidor amb el SGBD
  $db   = 'logins';     // Base de dades
  $user = 'louser';     // usuari amb permisos 
  $pass = 'L01o2#2526'; // password
  $charset = 'utf8mb4';

  /* 
  $user = 'louser';     // usuari amb permisos 
  $pass = 'L01o2#2526'; // password
  */

  $dsn = "mysql:host=$host;dbname=$db;charset=$charset";
  $options = [
      PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
      PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
      PDO::ATTR_EMULATE_PREPARES   => false,
  ];

  try {
      $pdo = new PDO($dsn, $user, $pass, $options);
  } catch (PDOException $e) {
      exit('Error de connexió: ' . $e->getMessage());
  }
  ?>

    Registre

      //----------registre.php----------//
  <?php
  session_start();
  require 'bd.php';

  if ($_SERVER['REQUEST_METHOD'] === 'POST') {
      $usuari = trim($_POST['usuari'] ?? '');
      $password = $_POST['password'] ?? '';

      if (strlen($usuari) < 3 || strlen($password) < 8) {
          $error = "Usuari o contrasenya massa curts.";
      } else {
          // Comprovar si ja existeix
          $stmt = $pdo->prepare("SELECT id FROM users WHERE usuari = ?");
          $stmt->execute([$usuari]);
          if ($stmt->fetch()) {
              $error = "El nom d’usuari ja existeix.";
          } else {
              $hash = password_hash($password, PASSWORD_DEFAULT);
              $stmt = $pdo->prepare("INSERT INTO users (usuari, password) VALUES (?, ?)");
              $stmt->execute([$usuari, $hash]);
              $_SESSION['user'] = $usuari;
              header("Location: home.php");
              exit;
          }
      }
  }
  ?>

    Login

      //----------login.php----------//
  <?php
  session_start();
  require 'bd.php';

  if ($_SERVER['REQUEST_METHOD'] === 'POST') {
      $usuari = trim($_POST['usuari'] ?? '');
      $password = $_POST['password'] ?? '';

      $stmt = $pdo->prepare("SELECT id, password FROM users WHERE usuari = ?");
      $stmt->execute([$usuari]);
      $user = $stmt->fetch();

      if ($user && password_verify($password, $usuari['password'])) {
          // Opcional: regenerar la sessió per evitar fixation
          session_regenerate_id(true);
          $_SESSION['user'] = $usuari;
          header("Location: home.php");
          exit;
      } else {
          $error = "Usuari o contrasenya incorrectes.";
      }
  }
  ?>

  <!DOCTYPE html>
  <html lang="ca">
  <head>
    <meta charset="UTF-8">
    <title>Inici de sessió</title>
  </head>
  <body>
    <h2>Iniciar sessió</h2>
    <?php if (!empty($error)) echo "<p style='color:red'>$error</p>"; ?>
    <form method="post">
      <label>Usuari: <input type="text" name="usuari" required></label><br>
      <label>Contrasenya: <input type="password" name="password" required></label><br>
      <button type="submit">Entrar</button>
    </form>
    <p><a href="registre.php">Crear compte nou</a></p>
  </body>
  </html>

    Home

      //----------home.php----------//
  <?php
  session_start();
  if (!isset($_SESSION['user'])) {
      header("Location: login.php");
      exit;
  }
  ?>

  <head>

      <button type="submit">Tancar sessió</button>

  </html>

    Logout

      //----------logout.php----------//
  <?php
  session_start();
  $_SESSION = [];
  session_destroy();
  header("Location: login.php");
  exit;
  ?>
