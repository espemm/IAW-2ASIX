    Pràctica 1: Instal·lació d’un servidor LEMP¶

    Objectiu¶

    • Instal·lar un servidor LEMP per desplegar diferents tipus d’aplicacions.

    Tasques a fer¶

    Realitza aquesta pràctica en una màquina virtual.

    LEMP és un acrònim de les tecnologies utilitzades:

    • Linux — sistema operatiu\
    • E nginx — servidor web\
    • MariaDB / MySQL — sistema de bases de dades\
    • PHP — llenguatge de programació del costat del servidor

    Configurarem un entorn LEMP en Linux.

    Passos detallats¶

    Instal·lació del servidor de base de dades¶

    Instal·la MariaDB:

    apt install mariadb-server

    Executa la configuració segura inicial:

    mariadb-secure-installation

    Crea una base de dades i un usuari nou:

    mysql -u root -p
CREATE DATABASE newdb;
CREATE USER 'username'@'localhost' IDENTIFIED BY 'userpassword';
GRANT ALL PRIVILEGES ON newdb.* TO 'username'@'localhost';
FLUSH PRIVILEGES;
quit

    Instal·lació de Nginx i PHP¶

    Instal·la els paquets necessaris:

    apt install nginx php php-fpm php-mysql
    • nginx: servidor web
    • php-fpm: permet executar PHP des de nginx
    • php: llenguatge PHP (versió 8.2 en Debian 12)\
    • php-mysql: llibreria PHP per connectar-se a MariaDB/MySQL

    Verificació del funcionament de nginx¶

    Accedir, des del navegador, a la pàgina web d’inici del servidor:

    http://<adreça_ip>

    Verificació del funcionament de PHP¶

    Caldrà tindre en la configuració del lloc:

    location ~ \.php$ {
    include snippets/fastcgi-php.conf;
    fastcgi_pass unix:/run/php/php8.1-fpm.sock;
}
    On s’indica que quan arribe un arxiu .php es reenvie a php-fpm per a que se processe.

    Crea un fitxer info.php a /var/www/html amb el contingut:

    <?php phpinfo(); ?>

    Comprova que els fitxers servits per Apache són propietat de www-data:www-data.

    Accedeix des del navegador:

        http://<adreça_ip>/info.php
    I vorem la configuració del php instal·lat.

    Accés amb nom (resolució de noms)¶

    Per accedir amb un nom de domini, edita /etc/hosts:

    <adreça_ip_servidor>    www.exemple.com

    Després visita:

    http://www.exemple.com/info.php

    Revisió de registres (logs)¶

    Si hi ha errors, revisa:

    • /var/log/apache/access.log — registre d’accés\
    • /var/log/apache/error.log — registre d’errors

    També pots utilitzar:

    journalctl -u apache2
