    🌐 Implantació web en servidors¶

    La implantació web és el procés de preparar, configurar i posar en funcionament una aplicació o servei web en un servidor accessible a través d’Internet o d’una xarxa local.

    Combina coneixements de xarxes, sistemes operatius, seguretat i programació web, amb l’objectiu de garantir que la web siga estable, escalable i segura.

    1️⃣ Infraestructures d’allotjament¶

    Hosting compartit

    En un hosting compartit, les aplicacions web comparteixen els recursos del servidor (CPU, RAM, espai de disc, etc.) amb altres llocs web que estan allotjats al mateix servidor físic.

    Exemples de proveïdors:

    • Hostinger
    • IONOS

    VPS (Virtual Private Server)

    En aquest cas, el servidor físic es divideix en diversos servidors virtuals o Virtual Private Server (VPS), on cadascun té assignats els seus propis recursos.

    Exemples de proveïdors:

    • OVH
    • DigitalOcean

    Servidor dedicat

    Un servidor dedicat consisteix en tindre un servidor físic complet on només s’allotjarà la teua aplicació web.

    Exemples de proveïdors:

    • Hetzner
    • swhosting

    Cloud Computing

    Cloud Computing és el terme que fa referència a la computació al núvol. El concepte de serveis es trasllada a servidors remots que implementen la infraestructua i serveis necessaris per a implementar o allotjar l’aplicació web, entre altres funcions.

    Principals proveïdors:

    • AWS
    • Azure

    2️⃣ Protocols de comunicació: HTTP i HTTPS¶

    HTTP (Hypertext Transfer Protocol)

    Protocol bàsic de la web. Defineix com es realitzen les peticions i respostes entre un client (navegador) i un servidor web.

    Funciona principalment pel port 80 i permet transmetre contingut com HTML, CSS, imatges o dades JSON.

    HTTPS (HTTP Secure)

    Versió segura d’HTTP, amb xifrat TLS (Transport Layer Security).

    Garanteix:

    1. 🔒 Confidencialitat: dades xifrades.
    2. 🧾 Autenticitat: identificació del servidor.
    3. 🧩 Integritat: dades no modificades.

    HTTPS usa el port 443 i és essencial en aplicacions amb dades sensibles.

    3️⃣ Entorns de servidor: LAMP i LEMP¶

    LAMP

    Acrònim de: -

    • Linux — Sistema operatiu
    • Apache — Servidor web
    • MySQL / MariaDB — Base de dades
    • PHP — Llenguatge de programació

    Popular per aplicacions PHP (WordPress, Moodle, Joomla…).

    LEMP

    Variant amb Nginx (Engine-X) en lloc d’Apache: - Linux

    • Engine-X
    • MySQL / MariaDB
    • PHP (via php-fpm)

    Nginx destaca per la seua eficiència i gestió de concurrència.

    4️⃣ Gestió de bases de dades amb phpMyAdmin¶

    phpMyAdmin és una eina web en PHP per administrar MySQL/MariaDB de manera gràfica.

    Permet:

    • Crear i modificar bases de dades i taules.
    • Gestionar usuaris i permisos.
    • Exportar/importar dades.
    • Executar consultes SQL.

    Ideal per a entorns educatius o de desenvolupament (en producció cal protegir-lo adequadament).

    5️⃣ Balancejament de càrrega (Load Balancing)¶

    Quan una aplicació rep moltes peticions, un únic servidor pot no ser suficient.

    Un balancejador de càrrega distribueix el trànsit entre diversos servidors per:

    • ⚙️ Repartir la càrrega.
    • 🧩 Millorar disponibilitat i escalabilitat.
    • 🔄 Garantir continuïtat del servei.

    Tipus principals:

    • Capa 4: connexions TCP/UDP.
    • Capa 7: contingut HTTP/HTTPS.

    Exemples: HAProxy, Nginx, AWS ELB, Traefik.

    6️⃣ Securització i bones pràctiques¶

    La securització (hardening) del servidor web és essencial per protegir-lo.

    Mesures bàsiques:

    • 🔐 Usar HTTPS amb certificats vàlids (Let’s Encrypt, CA pròpia…).
    • 🚫 Desactivar mòduls o serveis innecessaris.
    • ⚙️ Configurar permisos correctes dels fitxers web.
    • 🧱 Activar firewalls (UFW, iptables) i sistemes de detecció d’intrusions.
    • 🧾 Actualitzar regularment el sistema i paquets.
    • 📊 Monitoritzar logs i recursos amb journalctl, htop, fail2ban…

    7️⃣ Conclusió¶

    La implantació web combina configuració de servidors, seguretat i eficiència.

    Conéixer HTTP/HTTPS, entorns LAMP/LEMP, gestió amb phpMyAdmin, balanceig i securització és essencial per desplegar aplicacions web fiables, escalables i segures.
