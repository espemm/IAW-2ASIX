    🔐 El protocol HTTPS¶

    1️⃣ Què és el protocol HTTPS?¶

    HTTPS (Hypertext Transfer Protocol Secure) és la versió segura del protocol HTTP.

    Empra el protocol criptogràfic TLS (Transport Layer Security) per a:

    1. Xifrar les dades transmeses.
    2. Verificar l’autenticitat del client i del servidor.
    3. Assegurar la integritat de les dades.

    2️⃣ Quin port utilitza HTTPS?¶

    • HTTP → port 80
    • HTTPS → port 443

    3️⃣ Criptografia simètrica¶

    Utilitza una sola clau per a xifrar i desxifrar.

    Avantatge: ràpida.

    Inconvenient: la distribució segura de la clau.

    Exemple: AES (Advanced Encryption Standard)

    📚 Criptografia simètrica — Wikipedia

    4️⃣ Criptografia asimètrica¶

    Utilitza dues claus diferents:

    • Pública → per a xifrar
    • Privada → per a desxifrar

    Més segura però més lenta.

    Exemple: RSA (Rivest–Shamir–Adleman)

    📚 Criptografia asimètrica — Wikipedia

    5️⃣ Com funciona HTTPS¶

    • Pas 1. TCP 3-Way Handshake

      Client i servidor estableixen la connexió TCP inicial.

    • Pas 2. Validació del certificat SSL/TLS

    1. El client envia un ClientHello amb la versió de TLS i algoritmes de xifrat preferits.
    2. El servidor respon amb ServerHello i envia el seu certificat SSL/TLS.
    3. El certificat conté la clau pública i està signat per una CA.
    4. El client comprova la validesa del certificat.

    • Pas 3. Intercanvi de la clau de sessió

      El client genera una clau de sessió secreta, la xifra amb la clau pública del servidor i l’envia.

      El servidor la desxifra amb la seua clau privada.

    • Pas 4. Intercanvi de dades

      La comunicació posterior es fa amb xifrat simètric usant la clau de sessió compartida.

    6️⃣ Autoritat de Certificació (CA)¶

    Una CA és una entitat de confiança que emet i revoca certificats digitals per a garantir la seguretat de les comunicacions HTTPS.

    📚 Autoritat de Certificació — Wikipedia

    7️⃣ Tipus de certificats SSL/TLS¶

    Tipus Descripció Exemple
    Domini únic Vàlid per a un sol domini ieseljust.com
    Wildcard Vàlid per a un domini i subdominis *.ieseljust.com
    Multidomini (SAN/UCC) Vàlid per a diversos dominis ieseljust.com, altredomini.com

    SAN = Subject Alternative Name

    UCC = Unified Communications Certificate

    8️⃣ Què passa quan escrivim una URL?¶

    1. Resolució DNS del domini.
    2. Connexió TCP.
    3. Negociació TLS i validació del certificat.
    4. Comunicació segura i xifrada.
