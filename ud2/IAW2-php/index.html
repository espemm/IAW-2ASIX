    PHP¶

    PHP és un llenguatge de programació d’ús general utilitzat en el desenvolupament web.

    Veurem una xicoteta pinzellada centrada en l’ús de formularis.

    Llocs web que utilitzen PHP¶

    Molts llocs web utiilitzen PHP. Entre ells tenim:

    • WordPress
    • PrestaShop
    • Joomla

    Sintaxix bàsica¶

    Etiquetes d’obertura i tancament

    Inici amb <?phpi final amb ?>

    Les instruccions finalitzen amb ; al final de la línia

    <?php
    echo "Mostra per pantalla 1";
    echo "Mostra per pantalla 2";
?>

    Comentaris

    Comentar una linea amb // o # Comentar més d’una línia utilitzant /* al inici i */ al final

    <?php
    // Comentari d'una línia
    # Altre comentari d'una línia
    echo "Mostrar en php";

    /* Comentari de
     múltiples línias */
?>

    Variables

    Poden modificar el seu contingut durant l’execució. El nom de les variables comencen amb $ i és sensible a majúscules i minúscules.

    <?php
    $nom = "Adelaida";
    $curs = 2;
?>

    Constants

    No poden modificar el seu contingut durant l’execució. El nom de les constants no han de començar amb $ i és sensible a majúscules i minúscules.

    <?php
    define("PI", 3.1416);
    echo "El meu número PI és: ". PI;
    // El punt serveix per a concatenar la informació
?>

    echo

    Permet mostrar cadenes de text i contingut de variables i constants.

    <?php
    echo "Missatge de text";
    $num = 10;
    echo "Número: $num";
?>

    var_dump

    Permet mostrar el tipus i contingut d’una variable.

    <?php

$nom = "Eduard";
$edat = 20;
$nota = 8.5;

var_dump($nom);  // string(6) "Eduard"
var_dump($edat); // int(20)
var_dump($nota); // float(8.5)

?>
    print_r

    Mostra el contingut de una variable de forma legible.

    $llista = array("Sam", "Mary", "Tom");

print_r($llista);

//Array
//(
//    [0] => Sam
//    [1] => Mary
//    [2] => Tom
//)

    Formularis en PHP¶

    Una forma d’enviar informació al servidor és mitjançant l’ús de formularis.

    Exemple senzill de formulari

    <body>
    <form method="post" action="desti.php">
    Nom<br/>
    <input type="text" name="nom"><br/>
    Cognoms<br>
    <input type="text" name="cogns"><br/>
    <input type="submit">
    </form>
</body>

    La informació emplenada, si no s’indica el contrari, s’enviarà a la mateixa pàgina on estem. Amb action podrem dir-li al formulari que porte les dades a una altra URL.

    En l’exemple, al polsar Enviar s’executarà l’script desti.php en el servidor.

    L’script rebrà dos variables HTML anomenades nom i cogns amb les dades que haja teclejat l’usuari en el formulari.

    Si no s’indica mètode en method s’utilitzaria GET.

    En l’example, el mètode utilitzat per enviar les dades és POST, les dades s’hauran guardat en la variable global de PHP anomenada $_POST Aquesta variable és un array que s’indexarà amb el nom de les variables.

    <?php 
# Contingut del arxiu desti.php
    echo "El nom és ".$_POST['nom']."<br>" 
    echo "Els cognoms son ".$_POST['cogns']."<br>"
?>

    Si s’utilitza el mètode GET, en l’enviament del formulari, la variable que guardarà les dades del formulari sesrà $_GET

    Exemple Formulari - Enviament POST

    Codi html:

    <body>
    <form action="./respF.php" method="POST">
        <p>
            <!-- Camp nom -->
            <input type="text" name="nom" placeholder="Nom">
        </p>
        <p>
            <!-- Camp edat -->
            <input type="text" name="edat" placeholder="Edat">
        </p>
        <p>
            <!-- Camp email -->
            <input type="text" name="email" placeholder="Email">
        </p>
        <p>
            <!-- Botó submit -->
            <input type="submit" name="enviar" value="Enviar">
        </p>
    </form>
</body>

    Codi php:

    <?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {

    // Limpiar datos
    $nom = htmlspecialchars(trim($_POST['nom']));
    $edat   = htmlspecialchars(trim($_POST['edat']));
    $email  = htmlspecialchars(trim($_POST['email']));


    // Validar edat
    if (empty($edat)) {
        echo "El camp 'edat' és obligatorio.";
    } elseif (!filter_var($edat, FILTER_VALIDATE_INT)) {
        echo "L'edat ha de ser un número enter.";
    }

    // Validar email
    if (empty($email)) {
        echo "El camp 'email' és obligatori.";
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        echo "El email no té un format vàlid.";
    }

    // Mostrar resultats

    echo "<h3>Dades rebudes:</h3>";
    echo "<p><strong>Nom:</strong> $nom</p>";
    echo "<p><strong>Edat:</strong> $edat</p>";
    echo "<p><strong>Email:</strong> $email</p>";
}
?>
