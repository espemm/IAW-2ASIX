    Pràctica 5: WordPress - Modificar Tema¶

    ::: important

    Objectiu

    Modificar un tema existent de WordPress aplicant canvis al seu full d’estils (style.css), personalitzar el fitxer theme.json per afegir una paleta de colors i crear un tema fill utilitzant el plugin Create Block Theme.

    :::

    Part 1: Modifica el tema existent¶

    Selecciona un Tema

    1. Iniciar sessió al panell d’administració del WordPress.
    2. Aneu a Aparença > Temes i escolliu un tema instal·lat (per exemple, Twenty Twenty-Four).
    3. Activeu el tema seleccionat.

    \underline{Tasca}: - Prendre una captura de pantalla del lloc web abans de fer els canvis.

    Modifica l’arxiu style.css

    En la carpeta del tema seleccionat (wp-content/themes/nom-del-tema/), obri el fitxer style.css.

    Afegeix noves regles CSS per canviar l’aparença del lloc.

    \underline{Exemple} de canvis a style.css:

    /* Canvia el color de fons del cos */

body {
  background-color: #f5f5f5;
}

/* Personalitza el títol del lloc */

h1 {
  font-size: 32px;
  color: #0073aa;
  text-transform: uppercase;
}

/* Modifica enllaços */

a {
  color: #ff4500;
  text-decoration: none;
}

a:hover {
  color: #ff6347;
  text-decoration: underline;
}

    \underline{Tasca}:

    • Aplicar almenys tres canvis visuals al style.css.

    • Guardar els canvis i comprova el resultat recarregant el lloc web.

    Part 2: Personalitza l’arxiu theme.json¶

    Ubicar i Editar el Fitxer theme.json

    Dins la carpeta del tema (wp-content/themes/nom-del-tema/), localitza el fitxer theme.json.

    Afegeix una nova paleta de colors personalitzada dins del bloc “settings”.

    \underline{Exemple} de codi per a theme.json:

    { 
"versió": 2, 
"settings": { 
"color": { 
palette: [ 
{ "name": "Roig Intens", "slug": "roig-intens", "color": "#b22222" }, 
{ "name": "Blau Fosc", "slug": "blau-fosc", "color": "#00008b" }, 
{ "name": "Verd Neó", "slug": "verd-neó", "color": "#39ff14" } 
] 
} 
}
}
    1. Guardar els canvis i accedir a l’editor de WordPress.
    2. Anar a Aparença > Editor i comprovar que la nova paleta de colors està disponible.

    \underline{Tasca}:

    • Afegir almenys tres colors personalitzats a la paleta de theme.json.
    • Fer una captura de pantalla de la nova paleta a l’editor de WordPress.

    Part 3: Crea un Tema Fill amb Create Block Theme¶

    Instal·lar i Activar el Plugin Create Block Theme

    1. Al panell d’administració del WordPress, anar a Plugins > Afegeix Nou.
    2. Buscar Create Block Theme i instal·la’l.
    3. Activar el plugin.

    Crear un Tema Fill

    1. Anar a Aparença > Create Block Theme.
    2. Seleccionar l’opció “Create Child Theme”.
    3. Triar el tema pare (el que vas modificar anteriorment).
    4. Introduir un nom per al tema fill (ex. “El meu Tema Fill”).
    5. Fer clic a Create Theme.

    \underline{Tasca}:

    • Confirmar que el nou tema fill apareix a Aparença > Temes i activar-ho.
    • Navegar a la carpeta wp-content/themes/ i comprovar que s’ha creat la carpeta del tema fill.
